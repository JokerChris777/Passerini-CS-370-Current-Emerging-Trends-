# Passerini-CS-370-Current-Emerging-Trends-

Project Description
This project focuses on building a Pirate Intelligent Agent using Deep Q-Learning, a core reinforcement learning technique. The agent is trained to navigate a complex grid maze, successfully bypassing obstacles to reach a designated treasure destination. By combining neural networks with an exploitation-exploration framework, the agent shifts from random movements to executing highly optimized paths.

Technical Contributions
The foundational maze environment, rendering tools, and physics logic were provided as baseline code. My responsibilities centered on designing and implementing the agent's core decision-making intelligence. I constructed the Deep Q-Network using Keras, wrote the ε-greedy exploration algorithm, and implemented an experience replay buffer to stabilize neural network training and accelerate model convergence.
